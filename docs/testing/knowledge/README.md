# Verified Testing Knowledge

本目录保存跨测试场景复用、已经确认稳定的知识。

## 适合放这里的内容

- 稳定日志路径与诊断入口；
- 环境约束；
- 已确认产品行为；
- 稳定术语；
- 多个 Playbook 都需要引用的公共事实。

## 不适合放这里

- 第一次出现、尚未复现的现象；
- 对根因的猜测；
- 某次执行的完整日志；
- 只属于某个具体 Playbook 的操作步骤；
- 开发架构细节但对测试没有直接价值的内容。

## 推荐文件

- `logs-and-paths.md` — 已确认日志、状态与诊断入口。
- `known-behaviors.md` — 已确认且跨场景有价值的产品行为。
- `environment.md` — 测试环境的稳定约束与准备知识。
- `glossary.md` — 测试领域术语。

## 写入条件

写入本目录前应至少满足一个条件：

- 已重复验证；
- 有直接、稳定证据；
- 产品/测试接口明确保证该行为。

否则先写入 `../LEARNINGS.md`。
